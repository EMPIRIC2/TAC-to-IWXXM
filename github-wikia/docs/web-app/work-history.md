# Work history and privacy

This page describes saved sessions and local storage controls in the web app.

## Work history when signed in

1. Sign in with your organization account.
2. Open the work-history sidebar or history page.
3. Select a past session to restore TAC and prior outputs.
4. Continue edit, convert, and validate from that restored state.

## Guest drafts

1. Download XML promptly when you work as a guest.
2. Make sure that you know that a browser clear can remove local drafts.
3. Sign in when you need cloud work history.

## Privacy settings

1. Open privacy settings from the site footer.
2. Read the controls for optional local storage.
3. Adjust the settings when you share a workstation.

## Automated ingest

Some sites run an automated ingest worker that polls weather feeds and stores
reports near real time. Treat that ingest path as the primary path for routine
traffic when the worker is active. Use manual paste and convert for ad-hoc
fixes, training, and recovery.

Ask your systems contact whether ingest is active for your center.

## Sign-in problems

| Symptom | What to do |
|---------|------------|
| Cannot sign in | Make sure that the site URL, account, and network are correct. Use only the approved password reset flow. |
| History empty | Sign in. Open privacy settings. Make sure that you are not in guest mode. |
| Destinations missing | Destinations are likely disabled for your site. Download XML and use local channels. |
