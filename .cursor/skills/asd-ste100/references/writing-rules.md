# ASD-STE100 Issue 9 — writing rules (agent checklist)

**Source of truth:** ASD-STE100 Simplified Technical English, Issue 9
(2025-01-15), Part 1. This file is a condensed operational checklist for agents.
It is not the standard and does not replace Part 1 or Part 2.

**Counts:** 53 rules in 9 sections + GR-1…GR-8 (recommendations, not rules).

Sentence limits at a glance:

| Text type | Max words per sentence |
|-----------|------------------------|
| Procedural (incl. warnings/cautions) | 20 |
| Descriptive | 25 |
| Notes | 25 (descriptive only; no commands) |
| Paragraph | ≤6 sentences; one topic |

---

## Section 1 — Words

| Rule | Do |
|------|----|
| 1.1 | Use dictionary-approved words, technical nouns, or technical verbs only. |
| 1.2 | Use approved words only as the listed part of speech. |
| 1.3 | Use approved words only with approved meanings. |
| 1.4 | Use only approved verb/adjective forms. |
| 1.5–1.11 | Technical nouns: fit a category; short; consistent; no slang; do not use as verbs. |
| 1.12–1.13 | Technical verbs: fit a category; prefer dictionary verbs first; do not noun them. |
| 1.14 | American English spelling unless quoted text must stay. |

Technical noun categories (summary): parts, vehicles/locations, tools, materials,
facilities, systems, math/science, navigation, numbers/units, quoted text, roles
orgs, body parts, personal effects, medical, documents, environment, colors,
damage, ICT, operations, law, life forms.

Technical verb categories (summary): manufacturing processes; computer
processes; subject-field verbs; law/regulation verbs.

## Section 2 — Multi-word nouns

| Rule | Do |
|------|----|
| 2.1 | Multi-word nouns ≤3 words; break with prepositions when needed. |
| 2.2 | If longer: write full form once, then shorter form and/or careful hyphens. |

## Section 3 — Verbs

| Rule | Do |
|------|----|
| 3.1–3.2 | Only dictionary forms/tenses: infinitive, imperative, simple present/past/future, past participle as adjective. |
| 3.3 | Past participle as adjective is allowed (condition), not as hidden passive. |
| 3.4 | No auxiliary stacks that make perfect/progressive/complex forms. |
| 3.5 | `-ing` only as technical noun or modifier in a technical noun (few dictionary exceptions). |
| 3.6 | Active voice. Passive in descriptive text only if agent unknown. |
| 3.7 | Prefer an approved verb for the action, not a noun paraphrase. |

## Section 4 — Sentences

| Rule | Do |
|------|----|
| 4.1 | Short, clear; one topic (descriptive) or direct instruction (procedural). |
| 4.2 | No omitted words; no contractions. |
| 4.3 | Vertical lists for complex sets (colon lead-in; parallel items). |
| 4.4 | Connecting words/phrases for related sentences. |
| 4.5 | Use articles/demonstratives where applicable; do not telegraph. |

## Section 5 — Procedural writing

| Rule | Do |
|------|----|
| 5.1 | ≤20 words per sentence. |
| 5.2 | One instruction per sentence unless actions are simultaneous. |
| 5.3 | Imperative form. |
| 5.4 | Condition first, then comma, then command. |
| 5.5 | Notes = information only; never instructions. |

## Section 6 — Descriptive writing

| Rule | Do |
|------|----|
| 6.1 | Give information gradually; one subject per sentence. |
| 6.2 | Stable key words/phrases. |
| 6.3 | ≤25 words per sentence. |
| 6.4–6.6 | Paragraphs: related info; one topic; ≤6 sentences. |

## Section 7 — Safety instructions

| Rule | Do |
|------|----|
| 7.1 | Correct label (e.g. warning vs caution) for the real risk level. |
| 7.2 | Start with clear command or condition. |
| 7.3 | State the concrete result/risk. |

## Section 8 — Punctuation and word count

| Rule | Do |
|------|----|
| 8.1 | No semicolons; use two sentences. |
| 8.2–8.3 | Hyphens and parentheses per STE uses. |
| 8.4 | Colon ends lead-in sentence for word count; each list item is a new sentence. |
| 8.5 | Parenthetical group counts as one word in the outer sentence; count inner text separately. |
| 8.6 | Count as one word: numbers; number+unit; abbreviations; alphanumerics; quoted text; placard/title text; many proper nouns. |
| 8.7 | Hyphenated compounds count as one word. |

## Section 9 — Writing practices

| Rule | Do |
|------|----|
| 9.1 | Restructure the sentence when word-for-word swap fails. |
| 9.2 | Honor approved meaning and part of speech. |
| 9.3 | Do not invent phrasal verbs from approved words. |
| 9.4 | Keep terminology and wording consistent. |

### General recommendations (not rules)

- **GR-1:** Prefer `that` after verbs like `make sure`.
- **GR-2:** Re-read every `with`; remove ambiguity.
- **GR-3:** Only approved pronouns; replace ambiguous pronouns with nouns.
- **GR-4:** Make the referent of `this` clear.
- **GR-5:** Watch false friends.
- **GR-6:** Prefer English (“for example”) over Latin abbreviations (e.g., i.e., etc.).
- **GR-8:** Possessive `'s` only when clearly correct; otherwise rephrase.

## Quick Non-STE → STE patterns

| Avoid | Prefer |
|-------|--------|
| Long noun stacks | Break with `of` / `for` / `on` |
| Passive with known agent | Active subject + verb |
| `don't` / omitted articles | Full forms |
| Condition after command | Condition, then command |
| Semicolon splice | Two sentences |
| Abstract “is required” | Imperative or clear subject + verb |
