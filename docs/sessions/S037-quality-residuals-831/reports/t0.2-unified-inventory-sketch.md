# T0.2 — Unified inventory sketch (METAR/SPECI pilot)

**Session**: S037 / EV-030 · **Task**: T0.2 · **Status**: complete  
**Depends**: T0.1 design note  
**Specs**: TC-F29-004 · E30-T3 · S02.M1

## Purpose

Define the **in-scope pilot rule set** for the unified inventory index. Each row maps a
native ID → 20 matrix slots (5×4). M1 fills what it can; remaining slots must be explicit
`needs-fixture` (or `oos` with cite) — never silent.

## Index schema (proposed for M1 YAML)

```yaml
# tests/quality_matrices/inventory/metar_speci_pilot.yml
version: 1
product_scope: [metar, speci]
engines:
  lint:
    - id: INVALID_VISIBILITY
      native: { kind: registry_code, code: INVALID_VISIBILITY }
      slots: { happy: 5, sad: 5, edge_pass: 5, edge_fail: 5 }  # or per-slot status
  validate:
    - id: METAR_SPECI.AerodromeHorizontalVisibility-1
      native: { kind: schematron_pattern, pattern_id: METAR_SPECI.AerodromeHorizontalVisibility-1 }
  convert:
    - id: metar_nil
      native: { kind: encode_theme, stem: metar_nil }
```
