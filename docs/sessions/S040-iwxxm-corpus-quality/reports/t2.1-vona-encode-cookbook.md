### Feature 1 — Volcano (`MeteorologicalFeature`)

| IWXXM | From TAC / rule |
|-------|-----------------|
| `phenomenon` | `…/MeteorologicalFeature/VOLCANO` |
| `phenomenonGeometry` | `gml:Point` from `PSN` (decimal Lat Long, CRS EPSG:4326 / ERS as peer) |
| `phenomenonProperty` → `Volcano` | |
| → `name` | volcano name token |
| → `IAVCEINumber` | trailing number on `VOLCANO:` |
| → `sourceElevation` | `SOURCE ELEV` → `ElevatedLevel` MSL |
| → `activityStatus` | `ACT STS` → enum (see below) |
| → `onsetTime` / `duration` | from `ONSET` / `DUR` when not NIL; **omit** on A7-1 |

**`ACT STS` → `VolcanoActivityStatusType` (XSD):**

| TAC-ish token | Enum |
|---------------|------|
| `NIL` | `NIL` |
| `UNKNOWN` | `UNKNOWN` |
| `DECREASED ACT` / decreased | `DECREASED_ACTIVITY` |
| heightened unrest | `HEIGHTENED_UNREST` |
| eruption ongoing | `ERUPTION_ONGOING` |
| eruption occurred | `ERUPTION_OCCURRED` |

Lint negatives: unknown activity tokens → registry diagnostic (T2.2/T2.3).

### Feature 2 — Volcanic ash cloud (`MeteorologicalFeature`)

| IWXXM | From TAC / rule (A7-1 peer) |
|-------|-----------------------------|
| `phenomenon` | `…/MeteorologicalFeature/VOLCANIC_ASH` |
| `phenomenonGeometry` | `ElevatedLevel` elevation = `VA CLD HGT` (15 KM → 15000 M MSL) |
| `phenomenonProperty` | **`nilReason=http://codes.wmo.int/iwxxm/nil/inapplicable`** on A7-1 |

XSD also defines `VolcanicAshCloudVerticalExtent` (`heightSource`, `movement`) for
`VOLCANIC_ASH` features. **Official A7-1 does not use that type** — height source / movement
TAC labels are **not** serialized on the peer. Encoder default: **match A7-1** (geometry
level + inapplicable property). Optional deepen → child issue (gap G-VONA-1).

### Colour codes

- Vocabulary: `http://codes.wmo.int/iwxxm/AviationColourCode` (SCH patterns
  `VolcanoObservatoryNoticeForAviation.*ColourCode`).
- Prefer existing `tac2iwxxm.codelists` helpers (`UNKNOWN` / `NIL` / `NOT GIVEN` →
  `UNASSIGNED` under `iwxxm/` register).
- Do **not** emit legacy `49-2/AviationColourCode` on VONA 2025-2.

### Nil / missing (XSD + peer)

| Condition | Representation |
|-----------|----------------|
| Colour unknown / not given | nillable colour + `UNASSIGNED` href **or** `@nilReason` per SCH |
| Ash cloud height unknown | nil `ElevatedLevel` + `iwxxm/nil/unknown` (XSD doc on vertical extent) |
| No volcanic cloud | nil geometry / heightSource / movement + `inapplicable` (XSD) |
| Volcano name / position / elev unknown | nil + `iwxxm/nil/unknown` (`Volcano` / MetFeature docs) |
| `ONSET`/`DUR` NIL | omit optional elements (A7-1) |
| Incomplete TAC | translation-failed path + `translationFailedTAC` — no partial operational IWXXM |
