# ICAO OPMET Data Exchange Compliance

Implementation guide for ICAO OPMET Data Exchange Guidelines compliance in the METAR to IWXXM Translation Centre.

## Overview

This Translation Centre implements ICAO Doc 10003 "_Manual on the Digital Exchange of Aeronautical Meteorological Information_" **Section 7** requirements for translation centre operations, statistics collection, and data exchange.

> **Edition caveat (2026-07-14):** §7 is cited from the **published / store** Doc 10003. An Advance 2014 unedited draft (Amd 76 / IWXXM v1) has **no Section 7** and an empty metadata chapter — see [mining/ICAO-Doc-10003-draft-2014-mining-notes.md](../mining/ICAO-Doc-10003-draft-2014-mining-notes.md). Runtime attribute names follow vendored IWXXM **v2025-2** `common.xsd`, not that draft.
>
> **Public companion:** [Guidelines for the Implementation of OPMET Data Exchange using IWXXM (5th Edition, Oct 2023)](../mining/OPMET-IWXXM-Exchange-Guidelines-5th-mining-notes.md) — Translation Centre bulletin flow (§4.1.3 / §5.3), `permissibleUsage`, partial-translation minimum fields, AMHS/FTBP filename, and ROC/RODB validation statistics (**Guidelines §7** is exchange/implementation metrics, not identical to Doc 10003 §7). Archive minima there (28 days data / 2 months translation logs) are below this project's indefinite retention decision.

### IWXXM Document Metadata

All IWXXM XML documents generated by this Translation Centre include the following metadata attributes on the root element:

```xml
<iwxxm:METAR 
    translationCentreName="NOAA Meteorological Development Laboratory"
    translationCentreDesignator="NOAA-MDL"
    translationTime="2026-02-13T10:30:00Z"
    translatedBulletinReceptionTime="2026-02-13T10:29:45Z"
    translatedBulletinID="SAXX99KWBC130000"
    permissibleUsage="OPERATIONAL">
    <!-- IWXXM content -->
</iwxxm:METAR>
```

**Attributes:**
- `translationCentreName`: Full name of translation centre
- `translationCentreDesignator`: Short designator (NOAA-MDL)
- `translationTime`: ISO 8601 timestamp when TAC→IWXXM translation completed
- `translatedBulletinReceptionTime`: When original TAC bulletin was received (if applicable)
- `translatedBulletinID`: WMO bulletin identifier (if applicable)
- `permissibleUsage`: Always "OPERATIONAL" for this centre

### HTTP Response Headers

All API responses include Translation Centre identification headers:

```http
HTTP/1.1 200 OK
X-Translation-Centre: NOAA-MDL
X-Translation-Centre-Name: NOAA Meteorological Development Laboratory
X-ICAO-Location-Indicator: KWBC
Content-Type: application/json
```

These headers enable automated identification of the translation centre without parsing response bodies.

## ICAO Region Mapping

### Supported Regions

The Translation Centre automatically determines ICAO regional office jurisdiction based on airport ICAO codes:

| Region Code | Region Name | Example Airports |
|-------------|-------------|------------------|
| **NAM** | North American | KJFK (New York), CYYZ (Toronto), MMMX (Mexico City) |
| **EUR** | European | EGLL (London), LFPG (Paris), EDDF (Frankfurt) |
| **APAC** | Asia Pacific | RJAA (Tokyo), WSSS (Singapore), ZBAA (Beijing) |
| **MID** | Middle East | OMDB (Dubai), OEJN (Jeddah), OIII (Tehran) |
| **AFI** | Africa-Indian Ocean | FAOR (Johannesburg), HECA (Cairo), GMMN (Casablanca) |
| **SAM** | South American | SBGR (São Paulo), SCEL (Santiago), SKBO (Bogotá) |
| **NAT** | North Atlantic | _(Reserved for oceanic regions)_ |
| **WAFR** | West African | _(Subset of AFI)_ |
| **ESAF** | Eastern/Southern African | _(Subset of AFI)_ |

### Mapping Algorithm

1. **Single-letter prefixes** (K, C, M) → NAM
   - K = Continental USA
   - C = Canada
   - M = Central America/Mexico

2. **Two-letter prefixes** → Lookup in `ICAO_REGION_MAP`
   - Example: "EG" (UK airports) → EUR
   - Example: "RJ" (Japan airports) → APAC

3. **Fallback heuristics** for unmapped codes:
   - First letter E, L, U → EUR
   - First letter V, W, Z, R, P, N → APAC
   - First letter S → SAM
   - First letter F, G, H → AFI
   - First letter O, D → MID
   - Default → NAM

## Statistics Framework

### User Decisions

Based on user decisions for ICAO OPMET compliance:

1. **Indefinite Retention** (Decision 1): Translation statistics are retained indefinitely in PostgreSQL
2. **Webhook Notifications** (Decision 2): Configurable webhook notifications for translation events
3. **ICAO Region Tracking** (Decision 3): All translations tagged with ICAO region
4. **WGS84 Support** (Decision 4): Planned for Phase 4 implementation

```json
    "contact_email": "support@metar-iwxxm.example.org"
}
```

### Statistics Query

**POST** `/api/v1/translation/statistics`

Query aggregated translation statistics (requires authentication).

**Request:**
```json
{
    "start_date": "2026-02-01T00:00:00Z",
    "end_date": "2026-02-13T23:59:59Z",
    "icao_region": "NAM",                      // Optional filter
    "iwxxm_version": "2025-2",                 // Optional filter
    "airport_code": "KJFK",                    // Optional filter
    "include_airport_breakdown": true,
    "include_error_details": false
}
```

**Constraints:**
- Maximum date range: 90 days
- `end_date` must be after `start_date`
- Requires admin privileges

**Response:** See [Statistics Aggregation](#statistics-aggregation) schema above.

### Recent Statistics

**GET** `/api/v1/translation/statistics/recent?hours=24&icao_region=NAM`

Convenience endpoint for recent activity (requires authentication).

**Query Parameters:**
- `hours`: 1-168 (default: 24)
- `icao_region`: Optional ICAO region filter
- `iwxxm_version`: Optional version filter

## Configuration

### Environment Variables

```bash
# Translation Centre Identification
TRANSLATION_CENTRE_NAME="NOAA Meteorological Development Laboratory"
TRANSLATION_CENTRE_DESIGNATOR="NOAA-MDL"
ICAO_LOCATION_INDICATOR="KWBC"
SERVICE_ONLINE_SINCE="2024-01-15T00:00:00Z"
TECHNICAL_CONTACT_EMAIL="support@metar-iwxxm.example.org"

# Statistics Configuration
ENABLE_STATISTICS=true                # Enable statistics collection
STATISTICS_RETENTION_DAYS=            # Empty = indefinite retention

# Webhook Configuration (User Decision 2)
ENABLE_WEBHOOKS=false                 # Enable webhook notifications
WEBHOOK_URLS="https://example.org/webhook1,https://example.org/webhook2"
WEBHOOK_SECRET="your-webhook-secret"  # HMAC signature secret
```

### GIFTs Configuration

The GIFTs library is configured in `/GIFTs/gifts/common/xmlConfig.py`:

```python
# Translation Centre Mode (ENABLED)
TRANSLATOR = True

# Translation Centre Identity
TranslationCentreName = 'NOAA Meteorological Development Laboratory'
TranslationCentreDesignator = 'NOAA-MDL'
```

This enables Translation Centre metadata in all generated IWXXM XML documents.
