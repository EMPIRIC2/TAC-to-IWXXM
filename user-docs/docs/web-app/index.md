# Web app overview

The **web app** is the browser interface for TAC to IWXXM. Operators paste or
upload TAC, convert the text to IWXXM XML, examine results, and download files.

## Public hosts

| Environment | Web app URL |
|-------------|-------------|
| Production | `https://app.tac-to-iwxxm.com` |
| Staging | `https://app.staging.tac-to-iwxxm.com` |
| Local development | `http://localhost:18000` |

## Guest and sign-in

| Mode | What you get |
|------|----------------|
| Guest | Convert and download without an account. Cloud work history is not kept. |
| Sign in | Saved work sessions and features that need an account |

Use the email and password that your organization issues. Do not share passwords
in chat or email.

## Main tasks

1. Open [Convert and validate](https://github.com/EMPIRIC2/TAC-to-IWXXM/wiki/Web-app-Convert-and-validate) for the workbench steps.
2. Read lint notes and IWXXM output.
3. Download XML for your local archive procedure.
4. Open [work history and privacy](https://github.com/EMPIRIC2/TAC-to-IWXXM/wiki/Web-app-Work-history) when you sign in.

## Soft preview

**Soft preview** shows a live plain-language decode and a sketch while you edit.
Soft preview is advisory only. Treat Convert and Validate as the official path
for products that you share.

## Dissemination

Some deployments show send destinations after convert. Use only destinations
that your organization configures and approves. If the web app does not show
destinations, download the XML and use your normal send tools.

Never paste secret connection strings into shared tickets or chat.
