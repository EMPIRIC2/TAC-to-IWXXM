# TAC to IWXXM

Operator app for converting TAC reports to IWXXM. The original layout is at https://www.figma.com/design/ZB7OEoLx6j0Mwje8LHrFKd/METAR-2-IWXXM.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
